## Implementation

`PreparationSpec::MemorySnapshot` 记录 source、initializer、material、protected
publication 和配置的 ORT preparation budget，并计算饱和 peak。观察器不参与准入或结果。
它由 `prepareSingle()` 的单一 RAII terminal guard 调用：

1. `buildPackage()` 只填充快照，不报告终态；
2. 正常缓存 entry、计费和 publication commit 完成后才设置 `cacheEntryCommitted`；
3. post-publication、pre-cache-commit 取消先回滚 publication、释放 reservation，再报告；
4. `publicationRollbackAttempted` 只表示 rollback callback 已被调用；callback 异常不会
   被伪装成远端删除成功。
