# Spec189 ONNX materialization and r36 resource boundary

## Code change

The native preparation fallback now reads model and initializer files directly
into `std::vector<std::uint8_t>` with checked file-size and `streamsize` bounds. It
does not first create a large `std::string` and copy that string into a second
buffer. ONNX identity/manifest inspection keeps top-level external initializers
external, materializes only deep attribute/function tensors, and creates an
inference copy only for shape-value inputs required by a reviewed operator policy.
Unknown operators with captured external shape inputs fail closed. Deep payload
validation, duplicate external metadata rejection, cancellation checks and the
shared `maxAssembledBytes` budget remain active.

The read-only review-agent gate for the frozen assembler diff was `STATIC_PASS`.
The review covered graph/function scope, external/inline identity parity, policy
coverage, budget accounting and cancellation; it did not claim full-model runtime
qualification.

## r36 boundary

The maintained two-provider runner used the corrected global candidate with swap
disabled. Controller, Authority and both Providers reached readiness. During model
preparation the host guard stopped the run at
`RESOURCE_BOUNDARY:MemAvailable`: the minimum available memory was
`1557188608` bytes against the immutable `1610612736`-byte floor, with zero swap
used and zero swap-I/O delta. The largest process reached `4591411200` bytes RSS;
the aggregate run RSS reached the same value. The supervisor recorded a controlled
stop (`returncode=-15`) followed by an empty process list and cleanup.

No requester result, provider execution, terminal output, `run-record.json`, or
MiniNDN/Qwen qualification verdict was produced. This is a host resource boundary,
not a protocol failure and not a PASS. Raw samples remain under
`.codex-tmp/spec189-qwen-two-provider-20260918/runs/two-provider-global-r36/`.

The next useful boundary is a protected Repo/Provider consumer run with the same
per-initializer materialization rules. The memory floor must not be lowered merely
to convert this stop into a qualification result.
