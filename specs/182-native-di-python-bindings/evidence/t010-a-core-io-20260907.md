Boost.Asio context；没有第二个 Face、网络循环或 DI 类型。post 不内联、不等待，
只持调用方给出的函数，任务自行保持 owner 并处理异常。已在 CD-001 和 T010-A

CORE_IO_WAIT_FORBIDDEN，0ms 查询与 cancel 保留。共享 Face 仍由应用保持存活并运行。

源码审查覆盖生产 ServiceUser::BeginCollaboration 直接访问 m_pendingCalls 的前提、
post 无 raw-this capture、operation/user/handle 寿命、result 锁前拒绝，以及测试
从其他线程投递、同一 Face 执行、嵌套 post 不内联、Core 上 poll/cancel 和最终 owner 释放。
这些是调度/句柄单测，不是完整服务协作；没有用独立布尔状态替代网络资格。
