# T003 V3 Role Placement

## Design and Status

PARTIAL。新增 NativePreSplitFirstPlacement::proposeRoles 使用完整 NativeSelectionRoleV3
与仅 admission 可构造的 NativeAdmittedOfferV3。逐 role/rank 选择不同 Provider，先检查
backend/device/free GPU memory，再比较 loaded/assembled/canonical/cold、排队、等待、
RTT、带宽及确定性 Provider/device/backend 顺序。CPU 使用空 accelerator set，不合成 RAM。
输入 offer 再次核对 request/attempt/model/graph/deadline，拒绝 negative、重复或已过期 offer。
不使用 hasModel，不将 canonical 缓存当 exact reuse；loaded proof 需要完整身份、
process/runtime generation/fence、精确 device/backend/boot/topology。过期或未来 proof 不参与复用。

旧 NativeSplitCandidate 缺少完整 assembly/manifest metadata，旧简化 propose 仍有迁移债务；
proposeRoles 是同一策略的完整契约入口，下一步将真实准备结果接入并替换旧路径。
目前没有 requester 主链调用，不关闭 T003-C/T008-B/T010；不能把新增入口当端到端完成。
