## Closure decision

T002 的 Qwen ACK collection window 已完成 focused 验收：Qwen launcher 的默认窗口固定为
1000 ms，显式值必须满足 `0 < ackTimeoutMs < requestTimeoutMs`；native requester 读取并
输出同一配置，Core 的通用 5000 ms 默认值未改变。ACK deadline 现在只允许 timer callback
在真实 deadline 到达后关闭；过早 timer 会重新安排剩余窗口，显式的 role-coverage
early-close 路径保持不变。认证未完成时窗口延后关闭，关闭后 ACK snapshot 不再被修改，
取消、错误 token、解密失败、late/duplicate/negative ACK 不会绕过认证、冻结或 Selection
边界。

本项没有运行 MiniNDN、真实 Qwen 0.6B 两节点链路或外部 Trust Schema 签名验证，因此不
宣称 Spec190 完整验收或真实网络 latency 改善。
