## Changed gate

`tests/integration-tests/spec189-encrypted-repo-publication.t.cpp` 新增
`DurablePublicationServesAfterExecRestart` C++ selector，复用既有
`spec189-encrypted-repo` production target。父进程完成一次 durable cold
publication 后释放 `RepoCore` authoritative owner；子进程通过 `fork`+`exec`
重新构造 `RepoCore`/filesystem backend、Face、KeyChain 和 `ServiceUser`，调用
生产 `publishEncryptedLargeData` durable lookup/recovery API，并通过生产 Core
Interest callback 读取完整 envelope。

该 gate 不持久化旧 request、grant、session KV 或 plaintext key，也不修改
`RepoEncryptedLargeDataStore`/Core public contract。子进程只验证新的 serving owner
能读取既有不可变 envelope；这与后续 Provider 的授权解密 gate 明确分离。
