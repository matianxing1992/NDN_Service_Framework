cancellation-aware `ProtectedGrantFetcher`. `installNativeProtectedGrantFactory`
captures it and uses it only for exact grant retrieval; an empty callback keeps
the existing production `fetchNativeProtectedGrant` NDN transport. The
test-only `Provider::fromServiceProviderForTest` seam forwards this dependency
without replacing the production runtime factory. The served-provider C++ test
now writes the fail-closed authority registry and `0600` recipient key, leaves
the protected runtime factory empty, and verifies an exact grant-name lookup.

This is a production-approved transport dependency gate, not proof of the
standalone new-`ndn::Face` route against a real NFD. Real route-backed grant
transport, online Controller confirmation, revoke/rebind and negative fetch
qualification remain open.
