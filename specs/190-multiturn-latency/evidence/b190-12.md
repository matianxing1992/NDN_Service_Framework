## Changed gate

The gate is changed only if the named C++ selector reports all of the following in one
run: old API transient object removal, explicit durable commit surviving Source destruction,
idempotent explicit release deleting only the matching generation, cancellation leaving no
staging, and same-name replacement protected from a stale release. A compile-only result,
an isolated `RepoCore::remove`, or a protected compatibility-cache hit cannot close it.
