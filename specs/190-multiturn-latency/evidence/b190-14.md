## Changed gate

The first missing production boundary identified by B190-13 is now closed for
the in-process protected artifact path:

- `NativeGrantVerificationResult` preserves the authenticated grant `keyId`.
- `ProtectedRuntime` derives and owns a non-secret `NativeProtectedKeyReferenceV1`
  from `authorityIdentity + providerIdentity + modelManifestDigest +
  protectionEpoch + keyId`. Its canonical form is length-framed and its public
  identifier is a lowercase `sha256:` digest. It is available only while the
  runtime is authorized and is cleared with the protected runtime cleanup.
- `NativeAssembledEntryContext` carries the reference digest. The digest is
  included in the assembled-entry AAD and manifest, so a missing or different
  reference cannot authenticate an existing ciphertext.
- The protected assembler and Provider serving path fail closed with
  `DI_PROTECTED_KEY_REFERENCE_UNAVAILABLE` if grant verification did not produce
  the reference.

The reference deliberately excludes content keys, recipient private keys,
grant wire bytes, request/attempt, grant digest, provider boot/fencing state and
KV state. The protected assembler miss gate and staging-derived protected path
are unchanged.
