# T041 logging migration evidence — 2026-09-01

Status: focused implementation boundary **CLOSED**; the Spec175 design-to-code
convergence verdict remains `BLOCK` because T031 and T042 are still open.

## Change

All streamed-invocation producers under
`NDNSF-DistributedInference/cpp/ndnsf-di` now use the named ndn-cxx
`ndnsf.di.RuntimeEvidence` sink for machine-readable diagnostics:

- `DiTimelineTrace.hpp`
- `NdnsfCollaborationDependencyIo.cpp`
- `DependencyWaitScheduler.cpp`
- `NativeFaultInjection.cpp`
- `NativeProviderHandler.cpp` (including the legacy execution-control marker)
- the previously migrated coordinator, worker, and handler paths

Existing marker names and environment switches are preserved. Records are
assembled before logging, so concurrent output cannot interleave through a
multi-insertion standard stream. No direct `std::cout`, `std::cerr`, or
`std::clog` remains in the production directory. No prompt/answer text, token
keys, logits, or state tensors are added to the records.
