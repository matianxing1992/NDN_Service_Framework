```bash
  --run_test=Spec170NdnsfDiCoreFlow/Spec175NativeTinyOnnxI12ProviderUnavailableAfterEvent3WithReplacement \
```

The test uses the production C++ `BeginCollaboration`/ACK/Selection path with
two original role Providers and one spare Provider. The first terminal
Provider suppresses publication after the first three-token prefix. The user
callback starts one fresh Normal collaboration with `attemptEpoch=2`, the same
generation identity, a fresh event key/request ID, a replacement GroupCapability
projection, and a committed prefix `{4,5,6}`. The spare terminal Provider owns
the final role only for the second Selection.

```text

replacementExecutions=1 replacementEventsPublished=1
providerCoordinatorCompletions=4 publicationSuppressions=2
```

The first attempt is fenced when its event gap reaches the zero-retry budget;
the second attempt completes through the spare Provider and accepts End plus
Response. The test intentionally requires at least one delivered
post-reselection event rather than claiming that the fenced callback worker
replayed the pre-failure application prefix.
