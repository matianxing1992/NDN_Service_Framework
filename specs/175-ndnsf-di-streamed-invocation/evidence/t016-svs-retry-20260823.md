## Boundary correction

The earlier DummyFace `onSendData` fault hook observed no streamed-event Data:
the Provider publishes event Data through `SVSPubSub::publishPacket`, and the
User receives it through the SVS subscription callback. The hook was removed.

`ServiceProvider::setStreamPublicationInterceptorForTest()` now sits after
exact signed Data is inserted into the Provider IMS and before the SVS
publication. `setStreamRetentionInterceptorForTest()` can suppress retention
before IMS insertion for a permanent-gap negative. Both hooks are test-only;
production publication and exact-Interest paths are unchanged. The LocalMock
fixture now registers the same `/<provider>/NDNSF` and `/CK` filters as the
production constructor, so an exact event Interest is answered by the real
Provider `onInterest`/IMS path.
