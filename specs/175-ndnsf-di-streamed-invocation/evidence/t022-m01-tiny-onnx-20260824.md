and four Selection projections but lost cursor 1. The failure was not a model,
placement, or retry-oracle defect: the stream handler ran in the Provider worker

now dispatches the complete network-side commit to that owner while preserving
the synchronous writer contract. The Provider trace records committed cursors
1--9 and nonzero SVS sequence numbers.

failed before the fix and now passes. The complete 16-case

repository tests pass on the same host build.
