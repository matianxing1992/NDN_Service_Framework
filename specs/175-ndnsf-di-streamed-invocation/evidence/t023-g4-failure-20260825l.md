# T023 G4 failure: Apptainer HOME propagation

Date: 2026-08-25
Candidate: `spec175-final-candidate-20260825l`

## Observed result

The exact-SIF replay produced 30 entries, all with return code 1, before the
first application request. Every case failed in the NFD readiness phase; no
case reached ACK, Selection, Provider execution, or Response. The preserved
per-run evidence is under `results/spec175/g4/M01-r1` through `M10-r3`.

Representative error:

```text
WARNING: Overriding HOME environment variable with APPTAINERENV_HOME is not permitted
could not connect to NDN forwarder at /run/nfd/nfd.sock
RuntimeError: NFD startup failure: missing sockets for ; nfdc not ready for a,c,p0,p1,p2,p3,repo,u
```

The NFD logs show that the daemons created their per-node sockets and reached
normal route setup. The host-side `nfdc`/Face commands nevertheless used the
wrong client HOME because the launcher attempted `apptainer exec --cleanenv
--env HOME=...`. With Apptainer 1.5.3 this option is rejected for HOME and the
container retains the host HOME. A direct SIF probe reproduced the warning and
showed `HOME=/home/tianxing`; `--home <node-home>:<node-home>` correctly
selected the node-specific HOME.

## Classification

This is a host-orchestrator launcher contract defect at the host/SIF boundary,
not an NDNSF protocol failure, model failure, or missing SIF library. The SIF
runtime preflight remains valid for its own layer, but G4 is **FAIL** because
the real host replay cannot establish the per-node NFD management connection.

## Required repair and invalidation

Replace HOME environment injection in the production runner and generated
`nfdc` wrappers with Apptainer `--home`. Because the runner is sealed source,
the current candidate is invalidated: regenerate G0, rerun G1/G2/G3, build one
new SIF, rerun both preflights, and rerun the exact 30-entry G4 matrix. Do not
pool this failed matrix with G3 or retry it under a changed source identity.
