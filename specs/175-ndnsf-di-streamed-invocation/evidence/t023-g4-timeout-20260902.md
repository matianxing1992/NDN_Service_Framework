## Classification and action

This is an incomplete G4 replay/harness result, not an NDNSF protocol failure
and not a 29/42 qualification. The partial PASS count is retained as
diagnostic evidence only. The contract now requires a per-case watchdog,
all-four-Provider readiness, teardown proof before advancing, and explicit
`NOT_RUN` rows when a campaign deadline is reached. Before another replay,
inspect and, if needed, repair that replay-driver boundary. Any reproduction
must use the same source seal, profile, SIF, topology, seed map, and timeouts;
at most one byte-identical retry is allowed after the documented scoped cleanup.
