\diagramnote{两侧虚线分别表示 request 返回 handle、serve 返回 registration。这是关键对象关系的选择性视图：Client 还持有准备、admission、grant、conversation
等协作对象，未全部展开。Registration 持有自己的 State；不把它画成 HostState 本身，也不
把注册句柄关闭等同于已经停止远端任务。}
\callout{接线边界}{构造函数接收一个依赖，并不证明默认 request 路径已调用它。
当前路径与目标调用阶段分别见各自 G7；Provider 局部能力不代表 requester 全链完成。}
