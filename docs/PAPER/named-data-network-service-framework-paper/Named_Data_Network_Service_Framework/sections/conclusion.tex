NDNSF provides a general framework for building service-oriented distributed applications, supporting diverse service types and adapting to varied requirements. It enables fine-grained control over which providers can offer a service and which users can invoke it, and allows a single user to invoke the same service across multiple providers through protected solicitation, provider feedback, and user-side selection. In the original single-provider wired loss experiment, it completes more requests than NSC and as many as gRPC. With intermittently available providers, it outperforms fixed-provider configurations. The controlled NDNSF ablation shows that task-specific feedback improves completion under changing task capacity. Comparisons with failover-enabled baselines show no consistent completion advantage and higher latency and traffic. After disconnections, retrying an uncertain execution can duplicate work; avoiding such retries limits duplicate execution risk but can forgo recovery opportunities. Under one ABE authority, permission aggregation reduces initial distribution and rotation costs relative to separate ABE keys when permissions are numerous, but increases the cost of a single grant and is not cheaper than the tested batched-key alternative.

Future work will evaluate feedback under measured UAV workloads and quantify permission-update costs during live service operation.
