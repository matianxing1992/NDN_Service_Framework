NDNSF provides a general framework for building service-oriented distributed applications, supporting service publication, secure discovery, and invocation across diverse service types. It enables fine-grained control over which providers can offer a service and which users can invoke it, and allows a single user to select among multiple providers or request execution from several providers. Our evaluation shows higher completion rates than the fixed-provider baselines under the tested availability configurations. Comparisons with equivalent reselection and measurements of complete credential lifecycles remain necessary.

Under one ABE authority and the same set of public parameters, service permissions can be aggregated into one DKEY per entity while identity-signing credentials remain reusable and baseline trust rules focus on signing authority rather than service-permission lists. Measuring key-distribution and permission-update costs will help determine when this organization is advantageous.

As future work, we will further improve NDNSF’s performance. In particular, NAC-ABE currently exhibits performance degradation under high concurrency, we need to improve it or develop an alternative solution. We also plan to automate user and provider onboarding. Finally, we aim to develop additional real-world applications to further refine NDNSF’s design, especially for scenarios that benefit from its one-to-many service model.
