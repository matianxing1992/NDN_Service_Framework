Prior work on NDN and related ICN systems addresses remote invocation, multi-party communication, service discovery, and access control.

RICE~\cite{krol2018rice} studies remote method invocation in ICN, including a four-way handshake and parameter/result handling. NDNSF also handles inputs and results as named Data, while its Request--ACK exchange gathers participation feedback before a provider is selected.

NSC~\cite{meirovitch2021nsc} starts invocation with a signed Interest and describes application-defined trust schemas and encryption of input and result Data, with NAC as an option. Its design proposes multiple Executors under a shared name, although its reported demo uses one Executor and no payload encryption. NDNSF differs in collecting task-specific feedback from candidate providers before the user selects one; this adds coordination to the invocation.

DNMP~\cite{nichols2019dnmp} publishes measurement commands through Sync and collects replies. Its VerSec trust schema restricts which roles may publish commands for specified targets and probes. NDNSF likewise uses Sync to announce published requests to multiple participants, but applies this exchange to service invocation and provider selection rather than network measurement.

NDNSD~\cite{dulal2022ndnsd} supports service advertisement discovery and service-information updates, with optional NAC-ABE protection. It exposes measurements such as RTT and retransmission counts to applications. NDNSF can use NDNSD advertisements to identify candidates; its Request--ACK exchange then obtains feedback on whether they will participate in the current task.

NAC~\cite{zhang2018nac} automates named-data access-key distribution and examines how ABE reduces per-granularity key issuance. Enhanced NAC-ABE supplies KP-ABE, policy-bearing DKEYs, validation support, and key segmentation~\cite{dulal2023nac-abe}. NDNSF can protect task descriptors and uses ABE DKEYs to aggregate service permissions. The credential-object reduction follows from ABE permission aggregation; Section~\ref{sec:measured-permission-cost} examines its distribution and update costs.
