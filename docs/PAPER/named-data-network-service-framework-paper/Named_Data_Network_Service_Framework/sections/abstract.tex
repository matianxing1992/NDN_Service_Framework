Distributed service-oriented applications are increasingly prevalent, yet traditional IP-based service frameworks face fundamental challenges in scalability, reliability, and security. We present NDNSF, a data-centric service framework built on Named Data Networking (NDN). NDNSF supports both one-to-one and one-to-many service models, secure provider discovery, dynamic provider selection under changing resource availability, and fine-grained access control for users and providers. For scalability and reliability, NDNSF leverages NDN’s native multicast capability to disseminate published Request names to candidate providers via Sync. For security, NDNSF employs Name-based Access Control with Attribute-Based Encryption (NAC-ABE) to protect optional task descriptions in requests; request-scoped keys restrict input to selected providers and responses to the requesting user. Under one authority, NAC-ABE also consolidates an entity’s service permissions into a single decryption key, simplifying credential management. Moreover, providers acknowledge requests based on resource availability, while users select providers using customizable strategies based on runtime metrics such as computational capacity and network latency, enabling adaptation to changing system and network conditions.

We analyze the cost of creating, distributing, and updating user and provider credentials in NDNSF and evaluate its performance against NDN Service Call (NSC) and gRPC in wired and wireless environments. In single-provider wired experiments with packet loss, NDNSF achieves higher service-completion rates than NSC and rates comparable to gRPC. In scenarios with multiple intermittently available providers, NDNSF outperforms fixed-provider approaches by dynamically selecting available providers, resulting in substantially higher completion rates.
