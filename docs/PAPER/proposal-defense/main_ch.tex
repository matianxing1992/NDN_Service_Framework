\begin{abstract}
在命名数据网络（NDN）中支持分布式服务，需要在运行时发现愿意参与的 Provider、验证服务调用权限，并通过命名数据协调具有依赖关系的计算。本研究计划探讨 NDNSF 如何整合这些功能，并明确其安全保证与性能权衡。NDNSF 使用属性基加密（ABE）加密发现描述，使其仅对具有相应解密能力的获准 Provider 可读，无需 User 逐一列出其身份。服务授权则结合对加密 challenge 回应的核验、信任规则下的签名验证及请求状态检查。服务权限与身份签名凭证分离管理；获准但未选中的 Provider 仍可读取发现描述，选定后的应用输入与结果则采用请求级密钥保护。

拟议协作机制依据合格的肯定应答（positive ACK）Data 分配角色，并导出 Provider 本地的命名依赖准入规则。这些规则旨在将中间输入限定为由指定生产者角色沿声明依赖边提供的 Data，无论其来自生产者还是缓存。无人机多视角采集与识别以及分布式推理作为评估该方法的应用场景。

已有原型研究为特定配置下的服务调用、移动性处理和执行效率提供初步证据，为后续协作研究提供依据，但尚不能证明拟议协作机制的有效性。计划中的评估将比较完整授权方案，检验正常执行与故障恢复中的角色和依赖约束，并测量通信与处理开销。本研究旨在明确以数据为中心的发现、授权与协作在何种条件下改善分布式服务执行，以及何时其成本超过收益。
\begin{keywords}
Named Data Networking, service authorization, provider discovery, collaboration, distributed inference
\end{keywords}
\end{abstract}
