\begin{abstract}
请求者可能知道所需服务，却不知道哪些获准 Provider 当前可用且愿意执行。初版 NDNSF 在命名数据网络（NDN）上发现候选，并为一次调用选定一个 Provider，但不提供多角色协作。本研究计划评估这一基础，并研究面向相互依赖服务角色的扩展。

被评估设计采用属性基加密（ABE）保护发现描述，无需逐一列出 Provider 身份。服务授权由基于 ABE 的 challenge 核验、信任规则下的签名验证及请求状态检查共同实施，服务权限与身份签名凭证分离管理；运行时授予和撤销需要验证权限更新，撤销还需要换钥。获准但未选中的候选仍可读取发现描述；选定后的输入与结果交换采用请求级密钥保护。拟议协作扩展使用合格的肯定应答（positive ACK）Data 分配角色并导出本地依赖检查，旨在使 Provider 仅接受指定前驱沿声明依赖边提供的中间 Data，无论其来自生产者还是缓存。无人机与分布式推理应用为调用、数据交付、运行时授权及协作提供验证场景。

已有评估支持有限配置下的调用和执行效率结论，不证明拟议协作机制的有效性。计划中的评价将比较完整授权替代方案，检验执行与恢复中的角色和依赖约束，并测量通信、处理和管理成本。本研究旨在明确调用设计及其协作扩展何时有用，以及何时成本超过收益。
\begin{keywords}
Named Data Networking, service authorization, provider discovery, collaboration, distributed inference
\end{keywords}
\end{abstract}
