\begin{abstract}
本 Proposal 研究 NDN 服务框架如何发现当前愿意参与的 Provider、授权执行，并检查任务特定的命名数据依赖。NDNSF 使用 ABE-backed 授权，使缺少相应解密能力的实体无法读取发现 descriptor Content，同时将服务权限与身份签名凭证分离管理。获准但未选中的 Provider 仍能读取 descriptor；选定后的输入与结果采用请求级保护。

拟议协作机制依据合格 positive ACK 分配角色，并导出 Provider 本地命名依赖准入规则，补充 request ID 已有的隔离。签名或签名计划本身不证明结果真实或全局唯一提交。UAV 多视角采集与分布式推理用于共同验证研究问题。

已有实测对调用、移动切换、执行启动次数和小模型推理提供有限证据，不证明全部当前协作及原生推理特性。剩余工作包括完整授权替代方案比较、错误角色／依赖与恢复反例，以及开销和无收益条件的测量。本文区分实现、本地测试、实测结论和未闭合验收，并给出有条件的 Spring 2027 计划。
\begin{keywords}
Named Data Networking, service authorization, provider discovery, collaboration, distributed inference
\end{keywords}
\end{abstract}
