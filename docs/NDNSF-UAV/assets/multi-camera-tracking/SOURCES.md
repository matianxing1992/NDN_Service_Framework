# Multi-camera tracking slide assets

These small visual assets are copied from the public project repository so the
editable PowerPoint can be rendered without network access. They are not the
raw UAV video dataset.

- `uav1.jpg`, `uav2.jpg`, `uav3.jpg`, `Pipeline.png`
- Source repository: <https://github.com/JYe9/multi-camera-multi-vehicle-tracking-system>
- Dataset card: <https://huggingface.co/datasets/jye9/Multi-Camera-Multi-Vehicle-Tracking-System>

The slide deck retains the source and license boundary in its footers. Verify
the upstream project license before redistributing the assets or raw videos.
